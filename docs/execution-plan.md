# Execution plan

O proprietário define prazo, checkpoints, contingência e o responsável final pela entrega.

O prazo pertence ao projeto. Disponibilidade individual altera distribuição de tarefas, não a data final.

| Marco | Horário do projeto | Objetivo | Decisão se atrasar |
|---|---|---|---|
| Integração inicial | | Fluxo mínimo visível | cortar extras |
| Revisão de meio do prazo | | Reestimar trabalho restante | rebalancear ou cortar escopo |
| Congelamento de escopo | | Apenas entrega comprometida | bônus param |
| Integração final | | Teste e aceite | corrigir defeitos críticos |

Regra: sem deslocar ou cortar trabalho de custo equivalente, nenhuma proposta nova entra depois do congelamento.

## Escala proporcional

- Até 4h: primeiro fluxo ponta a ponta em até 25% do prazo; no máximo seis tarefas; integração frequente; bônus congelado cedo.
- Dias: fatias verticais independentes, checkpoints diários e contrato estável.
- Semanas+: épicos/stories, marcos de arquitetura e governança adicional conforme risco.

Cada orçamento inclui orientação, execução, revisão, integração e handoff. Se não couber, a tarefa está grande demais.
